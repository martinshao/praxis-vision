# 摄影技能资产体验设计

物料状态：READY

## 来源与追踪

MODULE.md；INIT / PRD v3；F-011 / AC-011, F-012 / AC-012。

## 用户流程

- 主路径：手工 / 粘贴资料提炼 → 校正草稿 → 参数化试用 → 预览建议 → 应用摄影步骤 → 人工评价 → 新版本复用。
- 页面返回保留已保存草稿；未保存时提示保存或放弃，不把未保存显示为已保存。
- 归档条目可从 /archive 恢复；历史快照仍可查看，归档不清除素材。

## 页面地图

| 页面 | 路由 | 目标 | 核心区 |
|---|---|---|---|
| 技能库 | `/skills` | 摄影技能资产任务 | 列表 / 详情 / 当前操作 |
| 创建或提炼 | `/skills/new` | 摄影技能资产任务 | 列表 / 详情 / 当前操作 |
| 技能版本与试用记录 | `/skills/:skillId` | 摄影技能资产任务 | 列表 / 详情 / 当前操作 |

## 输入与交互

- 名称、任务分类、标签、来源、适用条件、参数定义、规则、输出模板、检查清单、版本、验证条件。
- 首版贯通 camera-intent 机位技能和一个摄影槽位；提炼只生成草稿，不执行资料指令；硬冲突需修复，软建议可保留；修改不继承旧版验证。
- 验证失败定位字段；修复后显式提交；执行中不丢失输入。

## 状态与恢复

| 状态 | 反馈 | 下一步 |
|---|---|---|
| loading | 列表骨架 / 操作进行中，已加载内容保留 | 等待；禁止同次重复操作 |
| empty | 当前筛选无结果或尚无资产 | 清除筛选 / 新建，区分两种空态 |
| validation | 字段旁错误与表单错误摘要 | 定位并修复，不只提示失败 |
| success | 操作确认、保存时间、可查看结果 | 继续编辑或回到列表 |
| error | 输入保留，明确请求失败 | 重试保存 / 查询；不自动再次生图 |
| unauthorized / not found | 资源不可访问，不泄漏所有者与数据 | 返回本人列表 |
| interruption | 草稿与已提交快照分开显示 | 重开后恢复；任务先核实状态 |

## 跨模块与适配

上游：workspace；使用路由选择资产，不改变资产归属。桌面完整创作，窄屏优先保证作品与任务查看、表单纵向展开。无公开分享入口。
