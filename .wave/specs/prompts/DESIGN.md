# Prompt 资产体验设计

物料状态：READY

## 模块

prompts；INIT PRD v4 F-013–F-015 / AC-013–AC-015。

## 用户流程

入口：全局 Prompt；收集只要求非空原文，可后补标题、标签、来源和模型。保存→待整理→查找→详情选版本→载入快捷草稿→检查实际内容 / 未应用参数 / 素材 / 费用→显式提交→本人结果关联→选择封面 / 评价→另存新版本→再用。
作品详情“保存为 Prompt”保留实际文本和作品来源；详情“提炼为摄影技能”先预览发送内容、确认辅助提炼、人工校正后独立保存待试用草稿。可用手工提炼，不假称服务成功。
复用默认另建快捷草稿；已有未保存输入可选择另建或确认替换，取消保持原稿。不自动推断人物 / 风格。专业流程引用时仍需冲突预览与身份保护。

## 页面地图

| 页面           | 路由               | 目标                 | 核心组件                                                          |
| -------------- | ------------------ | -------------------- | ----------------------------------------------------------------- |
| Prompt 库      | /prompts           | 文字或本人结果找回   | 搜索、标签 / 题材 / 平台 / 模型 / 试用筛选、卡片 / 列表、收集入口 |
| 收集 Prompt    | /prompts/new       | 先收下原文           | 原文必填、来源链接、可后补条件、重复提示、保存                    |
| 条目详情与编辑 | /prompts/:promptId | 查版本 / 试用 / 复用 | 版本选择、原文与差异、编辑新版本、试用结果、封面、评价、来源      |

编辑在详情页新版本区域，不再增加编辑路由。静态 new 优先于动态 id。

## 交互状态

加载：局部骨架，保留已有输入；空库：收集入口；无匹配：清筛选；无图：原文摘要和“本版本未试用”。
保存失败保留所有输入，重试保存；并发冲突选择最新或另存，不能静默覆盖。重复原文提示已有条目：追加来源或明确另存，不按 URL 自动合并。
外链只显示元数据并由用户打开原站，不自动验证 / 请求；用户知道失效后可标不可用，本地原文仍可用。图片失败仅重读，不生成。
未试用 / 未评价 / 满意 / 待改进分开；评价只对一次结果和版本有效。新版无结果不继承评价；用户若选旧版封面明确标“来自旧版 vN”。新选封面只用本人成功且未归档结果，已有封面对应作品归档仍保留并标状态。
非人像：可保存 / 复制，生成按钮禁用并说明首版范围。缺服务 / 不支持条件列未应用项，用户确认适配草稿后再生成；失败 / 拒绝 / 未知沿用任务规则，未知先核实。
无权限与不存在统一返回本人库；离开未保存编辑先提醒。归档在默认库隐藏，归档筛选 / 全局归档可恢复，历史关联可读，不提供永久删除。

## 跨模块依赖与适配

库“载入快捷生成”跳 /quick；结果仍在旧任务系统；作品反向存 Prompt；技能只生成独立草稿；workspace 归档加类别；app-shell 聚合三入口。桌面主创作，窄屏单列收集 / 阅读，键盘可选版本 / 复制 / 关闭弹层，焦点回原入口。
