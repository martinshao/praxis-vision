## 共享约束

产品：praxis-vision，个人 AI 虚构人像创作者的私有工作台。界面用简体中文，项目名沿用已有名称；不新增品牌口号。
导航：项目、人物、摄影技能、摄影风格、作品；快捷生成常驻，归档次级入口。详情通过面包屑返回所属列表。
内容约束：只使用 AI 虚构人物；无真人照片上传、公开分享、永久删除、支付、团队、风光首版或模型训练。照片 / 人名 / 费用 / 测试结果使用清楚占位，不能伪造真实数据。归档始终解释为可恢复，不清除数据。设计 CTA 属于建议文案，不冒充最终批准。
设计系统：当前无 Stitch 项目设计系统，视觉方向为 PROPOSED。先在 Stitch 建立或选择一个统一系统，再按屏幕结构生成；若已有系统，继承它，不在单屏提示词重复颜色 / 字体 / 圆角 token。
响应式：Web，desktop-first，DESKTOP；建议桌面画布 1440px、窄屏变体 390px（画布宽度是排版假设）。1024px 以下参数栏分区展开；768px 以下导航抽屉、单列。窄屏优先保证作品和任务查看，复杂编辑纵向展开，不承诺新增完整移动产品范围。
可访问性：正文 16px / 1.5，独立标签与错误摘要，可见焦点、语义标题、图片替代说明、键盘可达、触控目标至少 44px、文字对比至少 4.5:1。状态不只依赖颜色，不强制 hover 或拖拽；减少动画。

## 统一设计系统提议（单独配置，不重复到每屏）

提议沿用现有 UI 方向：图片为中心的安静深色摄影工作台。背景 #18181B，面板 #27272A，主要文字 #FAFAFA，次要文字 #D4D4D8，浅色主按钮深色文字。系统中文无衬线回退，不加载外部字体，8px 间距基准。共享导航与参数面板宽度按现有 UI；阴影、圆角与未定义 token 留给统一系统，不编造品牌规范。此提议不是效果测试或用户品牌批准。

```text

PLATFORM: Web，desktop-first，device DESKTOP；为 390px 窄屏另作布局变体，不把所有状态塞进一个画布。

PAGE STRUCTURE:
1. 页头：人物、新建虚构人物。
2. 身份参考图片为主的卡片网格，名称、身份版本、归档标识；图片仅用 [AI 虚构人物参考图] 占位。

INTERACTIONS:
人物参考与拍摄造型区分；归档人物不默认参与新拍摄；不提供本地照片上传或拖入照片区域。

KEY STATES:
default：展示本页结构、主要动作和清楚占位。loading：局部骨架或进行中文字，保留导航与已加载内容。empty：区分无资产 / 无筛选匹配；表单页无资产列表时此状态不适用，改用未填写初始态。error：保留输入、明确失败原因与相应重试入口。success：显示真实操作结果和已保存状态，概念图仅用 [保存结果] 占位。disabled：重复提交或能力未配置时禁用并说明原因。validation：有表单时字段旁错误加可聚焦摘要；无表单列表页为不适用。unauthorized/not found：不泄漏他人资源，返回本人列表或登录。interruption：区分草稿和已提交快照，重开核实状态。
初始画布聚焦 default；loading / empty / error / validation / disabled / success 分别作为可点选的状态变体。不得用假照片、费用或验证记录伪装业务运行结果。

只使用 AI 虚构人物；无真人照片上传、公开分享、永久删除、支付、团队、风光首版或模型训练。照片 / 人名 / 费用 / 测试结果使用清楚占位，不能伪造真实数据。归档始终解释为可恢复，不清除数据。设计 CTA 属于建议文案，不冒充最终批准。
继承统一 Stitch 设计系统。本屏只规定结构、内容、层级与交互，不覆盖其 theme token。CTA 为建议文案，未知数据使用方括号占位；不增加 PRD 以外流程。
```
