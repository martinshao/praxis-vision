## 模块目标与边界

- 目标：按项目 / 人物 / 风格 / 标签筛选 → 详情 → 对比 / 收藏 / 满意 → 导出 → 复制方案再创作；归档后可恢复
- 模块内：适用筛选、标签、收藏、满意评价、图片原输出、任务与方案快照。
- 规则：快捷作品不虚构专业字段来源；旧版本继续可查；导出失败能重试；零满意作品不计算平均满意成本。
- 模块外：不承接其他业务模块的写入，不新增支付、分享、真人上传或永久删除。
