# 作品与复用体验设计

物料状态：READY

## 来源与追踪

MODULE.md；INIT / PRD v3；F-009 / AC-009。

## 用户流程

- 主路径：按项目 / 人物 / 风格 / 标签筛选 → 详情 → 对比 / 收藏 / 满意 → 导出 → 复制方案再创作；归档后可恢复。
- 页面返回保留已保存草稿；未保存时提示保存或放弃，不把未保存显示为已保存。
- 归档条目可从 /archive 恢复；历史快照仍可查看，归档不清除素材。

## 页面地图

| 页面 | 路由 | 目标 | 核心区 |
|---|---|---|---|
| 作品库 | `/works` | 作品与复用任务 | 列表 / 详情 / 当前操作 |
| 作品来源与复用 | `/works/:workId` | 作品与复用任务 | 列表 / 详情 / 当前操作 |

## 输入与交互

- 适用筛选、标签、收藏、满意评价、图片原输出、任务与方案快照。
- 快捷作品不虚构专业字段来源；旧版本继续可查；导出失败能重试；零满意作品不计算平均满意成本。
- 验证失败定位字段；修复后显式提交；执行中不丢失输入。

## 状态与恢复

| 状态 | 反馈 | 下一步 |
|---|---|---|
| loading | 列表骨架 / 操作进行中，已加载内容保留 | 等待；禁止同次重复操作 |
| empty | 当前筛选无结果或尚无资产 | 清除筛选 / 新建，区分两种空态 |
| validation | 字段旁错误与表单错误摘要 | 定位并修复，不只提示失败 |
| success | 操作确认、保存时间、可查看结果 | 继续编辑或回到列表 |
| error | 输入保留，明确请求失败 | 重试保存 / 查询；不自动再次生图 |
| unauthorized / not found | 资源不可访问，不泄漏所有者与数据 | 返回本人列表 |
| interruption | 草稿与已提交快照分开显示 | 重开后恢复；任务先核实状态 |

## 跨模块与适配

上游：workspace, studio；使用路由选择资产，不改变资产归属。桌面完整创作，窄屏优先保证作品与任务查看、表单纵向展开。无公开分享入口。
