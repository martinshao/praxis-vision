# 私有工作区与项目体验设计

物料状态：READY

## 来源与追踪

MODULE.md；INIT / PRD v3；F-001 / AC-001, F-010 / AC-010。

## 用户流程

- 主路径：空工作区 → 新建项目 → 保存 → 再次打开；归档列表 → 选择对象 → 恢复，历史关联不变。
- 页面返回保留已保存草稿；未保存时提示保存或放弃，不把未保存显示为已保存。
- 归档条目可从 /archive 恢复；历史快照仍可查看，归档不清除素材。

## 页面地图

| 页面       | 路由                   | 目标                 | 核心区                 |
| ---------- | ---------------------- | -------------------- | ---------------------- |
| 最近项目   | `/`                    | 私有工作区与项目任务 | 列表 / 详情 / 当前操作 |
| 拍摄项目   | `/projects`            | 私有工作区与项目任务 | 列表 / 详情 / 当前操作 |
| 项目详情   | `/projects/:projectId` | 私有工作区与项目任务 | 列表 / 详情 / 当前操作 |
| 归档与恢复 | `/archive`             | 私有工作区与项目任务 | 列表 / 详情 / 当前操作 |

## 输入与交互

- 项目名称（1–80 字）、标签（最多 20 个）、归档对象类别。
- 只操作当前所有者的资源；首版无公开分享、真人照片上传和永久删除；归档不删除数据。
- 验证失败定位字段；修复后显式提交；执行中不丢失输入。

## 状态与恢复

| 状态                     | 反馈                                  | 下一步                          |
| ------------------------ | ------------------------------------- | ------------------------------- |
| loading                  | 列表骨架 / 操作进行中，已加载内容保留 | 等待；禁止同次重复操作          |
| empty                    | 当前筛选无结果或尚无资产              | 清除筛选 / 新建，区分两种空态   |
| validation               | 字段旁错误与表单错误摘要              | 定位并修复，不只提示失败        |
| success                  | 操作确认、保存时间、可查看结果        | 继续编辑或回到列表              |
| error                    | 输入保留，明确请求失败                | 重试保存 / 查询；不自动再次生图 |
| unauthorized / not found | 资源不可访问，不泄漏所有者与数据      | 返回本人列表                    |
| interruption             | 草稿与已提交快照分开显示              | 重开后恢复；任务先核实状态      |

## 跨模块与适配

上游：无；使用路由选择资产，不改变资产归属。桌面完整创作，窄屏优先保证作品与任务查看、表单纵向展开。无公开分享入口。

## 私有会话入口

`/sign-in` 只允许预配置所有者登录。所有者邮箱 / 密码字段、提交中、字段错误、会话失效和登录成功状态完整；无注册或分享入口。未认证访问返回此页，returnTo 仅接受站内允许路由；登录后回到原任务。生成器 /login、/dashboard 示例不作为业务入口；APP-SHELL-001 移除示例页面，workspace/TASK-003 实现实际会话表单。
