# 产品模型

- Scope：INIT；对应 PRD v3；草案，未最终确认。
- 已确认范围：用户选择“先做人像，风光后续加入”（2026-09-15）。风格档案与组合先行，首版不训练模型亦已明确；其他建议均不等于批准。

## 意图、用户任务与目标

为持续创作数字人物摄影作品的人，将人物身份、摄影风格和拍摄意图变成可复用资产，减少反复编写提示词和整理文件的负担。

JTBD：当我想用同一个数字人物探索不同造型与摄影风格时，能保留人物身份、单独调整拍摄要素、比较结果并保存可再次创作的方案。

首批用户暂假设为个人 AI 人像创作者；商业团队是后续候选。用户规模与付费意愿未验证。

## 机会优先级与证据

1. 人物复用与迭代闭环：来自 E-001；E-002 表明参考能力存在但非完美保证。
2. 摄影语义的可控方案：来自 E-001；操作价值仍需用户实验。
3. 风格管理与复用：E-003 提供能力背景；用户已明确为可编辑风格档案与组合，先不训练模型。
4. 风光摄影：用户明确后续加入。

## 候选方案与取舍

| 方案 | 价值 | 成本 / 摩擦 | 决定 |
|---|---|---|---|
| 不开发，使用现有生图工具 + 提示词文档 + 文件夹 | 可以立即创作 | 身份、方案、结果关系需人工整理 | 保留为实验对照 |
| 只做长提示词生图 | 最短首图路径 | 人物与摄影流程价值难以体现 | 保留为快捷入口 |
| 固定但可返回修改的人像摄影流程 + 资产库 | 验证核心主张 | 需处理身份一致性、状态和回溯 | 推荐首版 |
| 自由节点工作流 + 模型训练 + 团队平台 | 控制面广 | 学习、运营与开发范围显著扩大 | 暂列后续候选，不擅自纳入 |

## 商业与运营模型

- 采用路径：发起人自用试验 → 邀请创作者试用 → 对照任务测量价值。暂不假设公开发布。
- 收益：节省到满意作品的时间，增加人物 / 风格复用；是否商业收费未确定。
- 首版建议不加入支付、订阅、积分售卖；生成服务费用仍是成本。
- 成本口径：全部生成尝试费用 / 被标记满意的作品数量，另计存储与服务运维。
- 运营责任：维护风格说明、生成能力清单与失败提示；供应商故障不能伪装生成成功。
- 外部约束：模型服务可用性、数据政策和商业使用条件需在架构前核查；本模型不选择供应商。

## 角色、权限与核心对象生命周期

用户已选定个人私有工作区，仅 AI 虚构人物，不上传真人照片或公开分享；允许生成素材发给生图服务。资产归属个人，首版只做可恢复归档。

| 对象 | 关系 / 归属 | 生命周期 | 规则 |
|---|---|---|---|
| 人物 | 创作者资产；方案引用人物版本 | 草稿 → 可用 → 归档 | 身份描述、身份参考与发色 / 服饰等可变造型分开；改造型不自动改写基础身份 |
| 摄影师 / 风格档案 | 创作者资产；方案引用风格版本 | 草稿 → 可用 → 归档 | 光线、构图、色调、镜头感、情绪及说明；首版允许档案组合，不训练模型；建议最多两档案按维度取用，冲突需处理 |
| 拍摄项目 | 包含多个方案与作品 | 草稿 → 创作中 → 已归档 | 一个项目聚合同主题探索，归档不等于删除 |
| 拍摄方案 | 属于项目，可复用人物和风格 | 草稿 → 已保存；修改另存版本 | 参数与提示词在提交时冻结，历史生成不受后续资产修改影响 |
| 生成任务 | 引用方案快照 | 提交中 → 排队 → 生成中 → 成功 / 失败 / 被拒绝；无法核实结果时状态未知 | 重复点击不创建多个同次提交；重试是新的显式操作 |
| 图片 / 作品 | 属于任务与项目 | 候选 → 收藏 / 满意 → 归档 | 评价不删除其他候选；标记“满意”用于指标统计 |

归档规则：人物、风格、技能、项目与作品可归档和恢复；归档不删除图片或历史快照，恢复保持关联。首版不提供永久删除，不宣称归档会清除生图服务持有的素材。

无协作者、公共分享者或支付角色。生图提交前展示发送的内容，未提交不传输。供应商保留与使用条件在接入前核查。

## 端到端用户旅程

首次进入空工作区 → 新建拍摄项目 → 创建虚构人物并选择身份参考候选 → 保存人物 → 选择 / 创建摄影风格 → 设置拍摄方案 → 检查提示词和生成选项 → 显式生成 → 对比候选 → 调整姿态 / 发色 → 再次生成 → 标记满意 → 保存、导出 → 下次从人物或作品重用方案。

快捷旅程：输入完整提示词 → 生成 → 比较 / 收藏 / 导出。快捷图可用于新建人物资产，但不自动推断完整专业方案，也不虚构不存在的人物关联。

退出与恢复：离开前草稿保存反馈；再进入恢复方案与任务状态。中断任务先查询结果，避免盲目再次付费生成。

## 信息架构、页面入口与核心交互

- 项目 / 首页：最近拍摄项目、新建项目、专业创作与快捷创作入口。
- 人物资产：列表、搜索、创建、身份参考选择、详情与版本。
- 摄影师 / 风格资产：档案列表、编辑、预览说明与应用。
- 创作工作台：人物 → 服化道 → 姿态 → 场景 → 摄影 → 生成与对比。步骤可返回，可选步骤不强制填写。
- 作品库：按人物、项目、风格与标签筛选；详情展示创作来源、收藏、满意、导出与重用。
- 任务记录：在创作页查看排队、生成、结果、失败与未知状态。

默认只设置必需的人物、文本意图与输出选项；风格可选。曝光三要素（光圈、快门、ISO）暂作为景深、动态和颗粒的视觉意图，而非真实物理仿真承诺，具体词义待评审。

## 功能规则、异常与恢复

- 空态：人物库为空时给创建入口；快捷入口不要求先建人物。
- 加载态：区分资产加载、任务提交和实际生成；无真实进度时不显示伪百分比。
- 验证：必需输入缺失、引用资产不可用或能力不支持时阻止提交，定位可修复字段。
- 冲突：结构化设置与自由文本冲突时显示提示词预览与冲突说明，不静默改写人物身份。
- 提交后：调整草稿不影响进行中的任务快照；完成结果归属于原方案。
- 错误 / 拒绝：保留输入与历史作品，明确失败或服务拒绝；重试前重新展示选项和可能成本。
- 状态未知：先核实结果；不可确认取消 / 费用时如实说明，不宣称退款或已停止。
- 无权限 / 不存在：禁止读取与提交引用，不泄漏其他工作区信息；首版没有多用户协作，个人资源不允许他人访问。
- 归档：历史仍可查看；归档资产不默认用于新拍摄。
- 局部修改：首版建议按身份参考重新生成；若需选区编辑，必须另增独立能力与验收，不能把两者混称。

## 可用性、可访问性与适配目标

建议桌面优先，窄屏至少可查看作品与任务，不承诺原生移动客户端。核心操作支持键盘、明确标签、可见焦点与文本状态反馈。色彩不是唯一状态线索。

用户无需理解模型节点即可完成核心任务。需真实测试：首次完成闭环、理解身份与造型的区别、找到失败恢复、从作品重用方案。

## 指标、假设实验与扩大/修改/停止条件

建议试验，不作为已验证 KPI：

- 5 名目标创作者完成同任务对照；若多数认为比文档 + 文件夹更难，先修改流程，不扩大功能。
- 5 个虚构人物 × 4 种单要素改变，两位评审分别判断身份保留、指定改变、无关要素稳定；建议至少 80% 身份保留通过，否则调整方法或缩小能力承诺。
- 闭环完成率 = 保存满意作品的创作会话 / 实际开始生成的创作会话；区分两个入口。
- 到满意结果的时间与全部生成次数、成本记录分布；目标基线未知，不虚构改善比例。
- 资产复用率 = 引用已有资产的拍摄方案 / 专业拍摄方案。
- 连续创作价值与费用同时达标才考虑扩大到风光或商业化；成本预算尚待用户指定。

### 风格组合首版细则（建议）

最多选择两个档案，分别取用光线、构图、色调等维度。冲突维度选择来源或输入新值；预览合成结果后另存新档案，记录来源版本，原档案不变。它是创作语义组合，不是训练模型或数值模型权重混合。

## 第二轮：摄影技能成为独立资产

用户要求将类似机位文章的摄影知识固化为可复用 skill。详细方案见 `INIT-SKILL-ASSETS.md`。

- 对象：摄影技能独立于人物、风格、拍摄方案；保存任务条件、输入参数、方法、规则、输出、检查清单、来源、依赖与验证记录。
- 大师：风格偏好 + 技能版本引用 + 可选工作流配方；技能可被多个大师共用。
- 生命周期：草稿 → 待试用 → 已验证 / 需调整 → 归档；修改创建版本，旧验证不自动继承。
- 旅程：新建 / 粘贴资料提炼 → 人工校正 → 参数化试用 → 应用到拍摄 → 生成与评审 → 保存记录 → 重复使用或另存新技能。
- 页面：增加技能库与技能详情 / 编辑；专业摄影步骤和快捷入口可选择应用；作品详情显示技能执行来源。
- 规则：缺参数定位；软建议可保留；冲突先预览解决；人物身份和用户配置不能静默覆盖；生图仍显式触发。
- 首版建议：声明式技能，只贯通机位技能和摄影槽位；分类、检索、提炼、编辑、试用、版本与追溯。其他槽位与多技能大师配方属于后续候选。
- 权限 / 删除：技能沿用已选定的个人私有工作区与可恢复归档规则；公开分享、交易、脚本执行不默认加入。
- 关联：F-011 / AC-011 技能资产；F-012 / AC-012 应用与执行记录；F-003、F-005、F-009 一并扩展。
