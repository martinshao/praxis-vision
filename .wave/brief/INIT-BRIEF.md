# SweetWave 产品简报

- 项目：praxis-vision
- 来源：`.wave/idea/INIT-IDEA.md`
- 状态：草稿，未经过调研或用户最终确认
- 说明：“已明确”来自原始想法；“建议 / 假设”用于收敛范围，仍待确认。

## 1. 一句话想法

打造以“虚拟摄影大师 + 虚拟人物形象管理”为内核的 AI 摄影工作台，通过可调整的摄影流程与可复用资产，创作风格化人像和风光作品，同时提供直接输入长提示词的快捷创作方式。

## 2. 目标用户

- 已明确：服务于希望通过 AIGC 创作摄影作品、控制创作环节并管理资产的人。
- 假设：首批用户是需要持续创作同一数字人物的 AI 人像创作者，以及希望将摄影知识转化为可复用流程的摄影爱好者。
- 待确认：优先面向个人创作、专业摄影师，还是商业内容团队。

## 3. 用户痛点

以下是从想法提炼的产品问题，尚未通过用户调研验证：

- 提示词承载人物、服化道、姿态、背景和摄影参数等多个变量，反复修改与复用较繁琐。
- 使用同一数字人物持续创作时，需要保留身份特征，并能单独调整发色、姿势等要素。
- 创作者希望借助不同摄影大师的风格知识，形成自己的风格化作品与可复用创作方法。
- 人物、风格、提示词、过程图与最终作品需要关联管理，便于复用和回溯。
- 有时需要逐步精调，有时只想输入一段提示词快速生成作品。

## 4. 核心场景

### 场景 A：可控的人像摄影流程（已明确）

通过提示词创建数字人物 → 调整服装、妆容、道具、姿态、背景与摄影要素 → 生成候选作品 → 根据结果继续调整 → 保存最终作品及关联资产。

典型操作：复用同一人物，改变姿势或发色；保留满意结果，再探索另一种方案。

### 场景 B：快捷人像创作（已明确）

输入一段完整提示词 → 直接生成作品，无需完成复杂的分步流程。

建议：快捷创作的结果也能归档；是否可转入专业流程继续编辑，待确认。

### 场景 C：摄影风格复用与组合（已明确方向）

选择虚拟摄影大师或风格 → 将风格用于创作 → 调整或组合不同风格，生成新的风格化照片。

“蒸馏摄影大师”暂解释为提炼与复用风格知识；是否涉及实际模型训练，未确认。

### 场景 D：风光摄影（已明确方向）

通过 AIGC 创作风光摄影作品，并调整风格与摄影要素。具体流程及与人像摄影的共用资产尚待定义。

## 5. MVP 边界

以下为建议范围，未视为用户批准：优先验证“同一数字人物的可控人像创作与资产复用”闭环，同时保留快捷生图入口。

- 数字人物资产：创建、保存、选择和复用人物，记录身份参考及基本特征。
- 专业人像流程：支持人物、服化道、姿态、背景、摄影要素的分步设置与调整。
- 生成与迭代：生成候选图，基于已保存方案调整一个要素并再次创作；人物一致性与局部调整效果须后续验证。
- 风格资产：提供少量可复用风格方案，验证虚拟摄影大师的产品表达。
- 快捷创作：完整提示词直接生成，并保存结果。
- 资产管理：关联人物、风格、创作配置、提示词与作品，支持再次使用和版本回溯。

建议风光摄影与复杂风格组合进入后续阶段；若它们是首发核心需求，应在 PRD 评审时调整范围。

## 6. 不做什么

以下是本轮 MVP 的建议取舍：

- 暂不扩展视频、社交社区、资产交易市场与多人协作。
- 暂不建立通用的任意节点工作流编辑器，先验证固定步骤是否满足创作需求。
- 暂不把自训练模型或摄影大师模型蒸馏设为必要前提。
- 不承诺任意修改都能完全保留人物身份、其他画面细节或精确呈现真实相机参数；这些是待验证能力。

## 7. 成功指标

以下为建议衡量方式，目标值待调研与试用后确定：

- 创作闭环完成率：从人物创建 / 选择到保存满意作品的比例。
- 达到满意结果的时间与生成次数：分别衡量专业流程和快捷入口。
- 人物一致性：同一人物跨姿态、发色与场景创作的人工评审通过率。
- 调整可控性：指定要素修改成功、需保留要素维持稳定的评审通过率。
- 资产复用率：已保存人物、风格或创作方案被再次用于创作的比例。
- 创作成本：每张满意作品的平均生成成本。

## 8. 待确认问题

1. 首批用户是谁？主要用于个人艺术创作，还是商业内容生产？
2. 首发是否接受优先做人像？风光摄影是否必须同时上线？
3. “虚拟摄影大师”是可配置的摄影顾问、风格预设，还是需要实际训练的风格模型？“蒸馏”具体指什么？
4. 数字人物来自纯提示词生成，还是也允许上传参考照片？人物一致性需要达到什么可接受标准？
5. 修改姿势或发色时，需要在原图上局部编辑，还是允许重新生成并保持人物与主要配置？
6. “摄影三要素”具体指曝光参数，还是光线、构图等创作控制？哪些要素必须独立可调？
7. 专业工作流是固定步骤，还是用户可自由编排？快捷生成与专业流程是否需要互相转换？
8. 资产管理首期需要哪些对象，以及怎样的分类、版本和检索能力？
9. 一次创作可接受的等待时间、尝试次数与成本上限是多少？
