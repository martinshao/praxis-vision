# 产品需求文档（PRD）

## 1. 项目信息

- 项目名：praxis-vision；Scope：INIT；版本：v2；物料状态：DRAFT。
- 产品形态：AI 人像摄影工作台；终端建议桌面优先，技术栈不在本阶段选择。
- 输入：INIT-IDEA、INIT-BRIEF、INIT-RESEARCH、INIT-MODEL。
- 明确决定：首版人像，风光后续；摄影大师采用可编辑风格档案与组合，先不训练模型。
- 未决关键边界：真人上传、工作区权限、第三方传输和删除规则，当前不能进入下游规划。

## 3. 背景

原始想法要求将虚拟摄影大师与人物管理作为内核，通过 AIGC 控制服化道、姿态、背景和摄影要素，同时支持长提示词直接生成。

官方资料表明人物参考、风格参考与局部生成编辑已有相关产品能力（E-002–E-004），但这些资料不证明本产品的生成质量或市场需求。产品机会假设是以摄影语言组织持续创作，并保留人物、风格、方案与作品的关系。

## 4. 目标

- G-001：同一人物跨造型、姿态与场景重复创作，保留可检查的身份参考。
- G-002：创作者能单独调整摄影要素，理解每次生成使用的配置，比较候选结果。
- G-003：保存与组合摄影风格档案，把摄影方法固化为参数化技能，重复使用人物、风格、技能和拍摄方案。
- G-004：既支持分步控制，也支持快捷长提示词入口，最终作品可查来源并导出。

生成质量、使用意愿与降低成本均需实验，不把用户确认 PRD 当作这些目标已被验证。

## 5. 目标用户

建议首批用户为持续创作虚构数字人物的个人 AI 人像创作者。是否允许真人参考及多用户需明确决定。团队商业内容生产、摄影服务商属于后续候选。

## 6. 用户场景

- S-001：创建人物并保存身份参考，用于多次拍摄。
- S-002：选择摄影风格，配置服化道、姿态、场景和摄影要素，生成并对比候选。
- S-003：保留人物和主要方案，改变发色或姿态后重拍，查看两次差异。
- S-004：编辑 / 组合风格档案形成新风格，并保存复用。
- S-005：完整提示词快捷生成，收藏、标记满意或导出。
- S-007：从文章、提示词或成功方案提炼摄影技能，人工校正后用于不同人物拍摄，检查效果与保存版本。
- S-006：从作品找到方案与资产版本，复用后继续创作；中断后恢复任务。

主路径：创建项目 → 创建 / 选择人物 → 选择 / 组合风格 → 配置拍摄 → 预览 → 生成 → 对比 → 调整重拍 → 保存满意作品 → 导出 / 再次复用。

## 8. 非功能需求

- 可用性：用户无需理解节点配置；每步有当前值与生成前预览。保存中、已保存、保存失败区分显示。
- 可访问性：核心路径可键盘操作；输入有标签、焦点可见、状态有文本，不只依赖颜色。
- 性能：建议常规资产浏览与草稿保存反馈在 2 秒内；测量环境和网络条件由验证时记录。生成耗时独立展示，不伪造百分比；服务目标待效果实验确定。
- 可靠性：提交快照不受新草稿修改影响；连续点击提交不造成同次重复任务；未知状态先查询，不自动盲重试。
- 安全与隐私：素材与凭据不写入公开文档或日志；上传 / 共享 / 工作区访问规则尚未批准，属于强制阻塞项。
- 数据一致性：人物和风格新版本不改写历史来源；归档与永久删除区分；后者必须有明确规则和可观察结果。
- 可观测性：记录任务状态、耗时、可知费用与失败类别；费用未知时显示未知，不捏造精确金额或退款。
- 兼容性：建议桌面浏览器优先；窄屏查看作品与任务可用，完整移动创作范围待评审。

## 9. MVP 范围

已决定：仅人像；可编辑风格档案与组合；不训练模型。

建议首版端到端切片：人物创建与复用、最多两档案的按维度风格组合、固定可返回拍摄步骤、预览、生成与任务恢复、整图重拍与对比、快捷生图、资产检索、满意标记、导出及归档。

本轮增加的建议切片：以“机位与视觉重点规划”贯通技能提炼 / 编辑 → 试用 → 应用 → 评审 → 版本复用。完整方法详见 `.wave/product/INIT-SKILL-ASSETS.md`；扩大到服化道、姿态、光线及多技能工作流配方另行评审。

个人工作区、无首版支付、整图重拍优先于选区精修是待评审建议。单一可用生图服务足以验证产品闭环，具体服务在后续架构阶段决定。

## 10. 非本期范围

风光摄影已明确后续加入。模型训练已明确首版不做。其他建议暂缓：自由节点编辑器、选区精修、视频、社交与资产市场、团队协作、订阅支付。若用户提出必要性，单独评审，不默认全部扩张。

## 15. 待确认问题

1. 首版是否仅个人私有工作区？人物能否来自真人参考？是否允许将素材发给生图服务？
2. 删除规则：是否采用“默认可恢复归档；永久删除仅用户明确操作；保留关联作品与已有配置快照，删除人物身份图时明确说明历史参考也受影响”？第三方保留情况待供应商核查。
3. 是否采用“先贯通机位技能”的首版切片？其他摄影技能、多技能大师配方随后扩展；整图重拍与按维度风格组合仍为待评审细则。

## 16. 指标与验证计划

- 研究限制：只有官方资料与发起人意图，没有用户访谈、可用性测试或生成效果实测。
- 建议对照：5 名创作者分别用本产品与提示词文档 + 文件夹完成同一人物两种拍摄；记录完成率、耗时、生成次数及主观摩擦。
- 身份 / 可控性：5 个虚构人物 × 姿态、发色、背景、风格四种改变；两名评审分别判断身份保留、指定改变、需保留要素；建议身份通过率至少 80%，阈值待试验评审，不宣称已通过。
- 风格组合：使用同一人物与场景，对比档案 A、档案 B 与组合；评审能否识别所选维度特征。
- 成本：所有尝试总费用 / 满意作品数；分入口统计，失败尝试不忽略；零满意作品时报告未定义及总投入。
- 复用率：使用已有资产的专业拍摄方案 / 全部专业方案；满意闭环率：保存满意作品的会话 / 已开始生成的会话。
- 扩大条件：重复创作价值与费用被用户接受，再扩展风光；未达到身份和控制效果目标时修改方法或缩小承诺；若核心流程比替代方案更繁琐，先简化，不增加外围功能。

## 17. 摄影技能资产与交互规则

技能是可复用的创作方法，人物保存身份，风格保存审美偏好，工作流组织技能顺序，方案保存本次输入，执行记录保存方法到结果的关系。

首版示例为原创的“机位与视觉重点规划”：输入画面目标、拍摄锚点与取景范围，并可配置观察方位、相对高度、镜头俯仰和背景存在感；输出方案字段、提示词片段和检查项。不同人物复用同一技能。

建议声明式方法，外部资料仅用于辅助提炼草稿；不自动执行外部指令、脚本、上传或生成。先人工校正、再试用与记录验证，未验证条目不得显示效果保证。

风格提供偏好、技能根据目标给建议、用户决定最终值。冲突预览，身份字段受保护；历史记录锁定版本。首版只贯通摄影槽位一个主要技能；按任务检索，查看来源与验证状态，填参数 → 预览 → 解决冲突 → 应用 → 生成 → 评价。

新增验证：至少两个人物、两种任务重复试用，记录目标是否达成；比较直接提示词与技能参数化路径的理解负担和复用时间。未执行前不报告效果通过。完整分析与原创示例见 `.wave/product/INIT-SKILL-ASSETS.md`。
