## 3. 背景

原始想法要求将虚拟摄影大师与人物管理作为内核，通过 AIGC 控制服化道、姿态、背景和摄影要素，同时支持长提示词直接生成。

官方资料表明人物参考、风格参考与局部生成编辑已有相关产品能力（E-002–E-004），但这些资料不证明本产品的生成质量或市场需求。产品机会假设是以摄影语言组织持续创作，并保留人物、风格、方案与作品的关系。

新增意图 E-009：发起人日常从社交平台收集 Prompt，缺少可管理、可视觉找回的资产入口。E-010 / E-011 官方资料提供文本与结果关联和生成条件记录的能力背景；不能据此声称复制 Prompt 即可复现作者效果。

## 4. 目标

- G-001：同一人物跨造型、姿态与场景重复创作，保留可检查的身份参考。
- G-002：创作者能单独调整摄影要素，理解每次生成使用的配置，比较候选结果。
- G-003：保存与组合摄影风格档案，把摄影方法固化为参数化技能，重复使用人物、风格、技能和拍摄方案。
- G-004：既支持分步控制，也支持快捷长提示词入口，最终作品可查来源并导出。

- G-005：跨平台收集的 Prompt 能找回、试用、查看本人结果并积累可追溯版本。

生成质量、使用意愿与降低成本均需实验，不把用户确认 PRD 当作这些目标已被验证。

## 5. 目标用户

首版面向持续创作虚构数字人物的个人 AI 人像创作者，采用个人私有工作区，不提供真人照片上传、多用户协作或公开分享。团队商业内容生产、摄影服务商属于后续候选。

## 6. 用户场景

- S-001：创建人物并保存身份参考，用于多次拍摄。
- S-002：选择摄影风格，配置服化道、姿态、场景和摄影要素，生成并对比候选。
- S-003：保留人物和主要方案，改变发色或姿态后重拍，查看两次差异。
- S-004：编辑 / 组合风格档案形成新风格，并保存复用。
- S-005：完整提示词快捷生成，收藏、标记满意或导出。
- S-007：从文章、提示词或成功方案提炼摄影技能，人工校正后用于不同人物拍摄，检查效果与保存版本。
- S-006：从作品找到方案与资产版本，复用后继续创作；中断后恢复任务。

- S-008：看到外部 Prompt，先保存原文和来源，不必先出图；以后通过文字与本人结果找回。
- S-009：把收藏 Prompt 载入快捷草稿，显式试用，选择结果为封面；修改成新版本，不误用旧版预览依据。

新增路径：收集 → 整理 / 检索 → 查看版本与条件 → 载入快捷草稿 → 显式试用 → 结果关联与封面 → 评价 / 改版 → 复用或辅助提炼技能。

主路径：创建项目 → 创建 / 选择人物 → 选择 / 组合风格 → 配置拍摄 → 预览 → 生成 → 对比 → 调整重拍 → 保存满意作品 → 导出 / 再次复用。

## 8. 非功能需求

- 可用性：用户无需理解节点配置；每步有当前值与生成前预览。保存中、已保存、保存失败区分显示。
- 可访问性：核心路径可键盘操作；输入有标签、焦点可见、状态有文本，不只依赖颜色。
- 性能：建议常规资产浏览与草稿保存反馈在 2 秒内；测量环境和网络条件由验证时记录。生成耗时独立展示，不伪造百分比；服务目标待效果实验确定。
- 可靠性：提交快照不受新草稿修改影响；连续点击提交不造成同次重复任务；未知状态先查询，不自动盲重试。
- 安全与隐私：素材与凭据不写入公开文档或日志；工作区私有，只使用 AI 虚构人物，不提供真人照片上传和公开分享；生图提交前明确将发送的提示词与生成素材；供应商的数据保留、训练用途与商业条件在接入前核查，不承诺第三方即时删除。
- 数据一致性：人物和风格新版本不改写历史来源；首版只有可恢复归档，不提供永久删除；归档不删除文件或历史快照，恢复后关联保持。
- 可观测性：记录任务状态、耗时、可知费用与失败类别；费用未知时显示未知，不捏造精确金额或退款。
- 兼容性：建议桌面浏览器优先；窄屏查看作品与任务可用，完整移动创作范围待评审。

- Prompt 可靠性：来源链接失效不丢手动保存原文；图读取失败仅重试读取；新版不继承旧版评价或结果依据。已知负面词 / 模型参数不受目标服务支持时列出未应用项并由用户决定，原文不静默改写。
- Prompt 隐私：仅手动粘贴和来源记录，不接入社交账户或自动抓取；收藏与预览不隐式传给第三方。调用辅助提炼或生图前展示实际发送内容并显式提交；外部示例不自动抓取、缓存或内嵌。

## 9. MVP 范围

已决定：仅人像；可编辑风格档案与组合；不训练模型。

建议首版端到端切片：人物创建与复用、最多两档案的按维度风格组合、固定可返回拍摄步骤、预览、生成与任务恢复、整图重拍与对比、快捷生图、资产检索、满意标记、导出及归档。

本轮增加的建议切片：以“机位与视觉重点规划”贯通技能提炼 / 编辑 → 试用 → 应用 → 评审 → 版本复用。完整方法详见 `.wave/product/INIT-SKILL-ASSETS.md`；扩大到服化道、姿态、光线及多技能工作流配方另行评审。

个人私有工作区与仅可恢复归档已选定。无首版支付、整图重拍优先于选区精修为当前方案细则。单一可用生图服务足以验证产品闭环，具体服务在后续架构阶段决定。

新增建议切片：手动收集、来源 / 标签 / 检索、完整文本版本、本人结果预览、显式快捷复用、作品反向存为 Prompt、复用已有辅助提炼机制和可恢复归档。跨题材收藏不扩大首版生成题材。详见 product/INIT-PROMPT-ASSETS.md。

## 10. 非本期范围

风光摄影已明确后续加入。模型训练已明确首版不做。其他建议暂缓：自由节点编辑器、选区精修、视频、社交与资产市场、团队协作、订阅支付、真人照片上传、公开分享和永久删除。若用户提出必要性，单独评审，不默认全部扩张。

Prompt 后续候选：社交抓取、OCR、浏览器插件 / 分享扩展、外部 AI 示例图片导入、语义 / 以图搜索、变量模板与片段组合、自动优化、跨模型自动适配、自动批量跑图、Prompt 市场、自动提炼风格档案。首版不将这些能力默认纳入。

## 12. 验收标准

- [ ] [AC-001] F-001：空工作区能新建项目并进入专业 / 快捷入口；保存后再次打开仍可查看同一项目。项目属于当前个人工作区，其他人不可查看或修改；不提供公开分享入口，不可通过资源地址绕过访问边界。
- [ ] [AC-002] F-002：提示词创建候选后能选择身份参考并保存人物；再次拍摄可选择该人物；人物改名或版本调整不更改历史任务的参考版本。
- [ ] [AC-003] F-003：能保存与应用风格档案；选择两个档案后能明确指定各维度来源，冲突维度必须择一或填写新值；组合预览、另存和后续复用保留最终值与来源；原档案不变，无模型训练步骤。
- [ ] [AC-004] F-004：返回修改姿态不丢失服化道与背景；未填写可选步骤可继续；专业路径缺失人物时定位创建 / 选择入口；草稿重新打开保留设置。
- [ ] [AC-005] F-005：生成前能查看最终描述；例如结构化发色与自由文本发色冲突时提示解决；实际提交文本可在作品详情查到；任务提交后改草稿不改历史文本。
- [ ] [AC-006] F-006：重复点击仅形成同次任务；排队与生成状态可区分；失败 / 拒绝保留输入与原作品；断网重新进入先核实状态；未知时不显示成功或自动重复付费生成；费用不可知时明确显示未知。
- [ ] [AC-007] F-007：复制已有方案只改姿态或发色后，创建新版本并提交；原人物身份参考及未改配置保持；原作品仍可查看并与新结果对比。配置保持与图像效果分开验收，身份通过率按第 16 节实验评估。

## 16. 指标与验证计划

- 研究限制：只有官方资料与发起人意图，没有用户访谈、可用性测试或生成效果实测。
- 建议对照：5 名创作者分别用本产品与提示词文档 + 文件夹完成同一人物两种拍摄；记录完成率、耗时、生成次数及主观摩擦。
- 身份 / 可控性：5 个虚构人物 × 姿态、发色、背景、风格四种改变；两名评审分别判断身份保留、指定改变、需保留要素；建议身份通过率至少 80%，阈值待试验评审，不宣称已通过。
- 风格组合：使用同一人物与场景，对比档案 A、档案 B 与组合；评审能否识别所选维度特征。
- 成本：所有尝试总费用 / 满意作品数；分入口统计，失败尝试不忽略；零满意作品时报告未定义及总投入。
- 复用率：使用已有资产的专业拍摄方案 / 全部专业方案；满意闭环率：保存满意作品的会话 / 已开始生成的会话。
- 扩大条件：重复创作价值与费用被用户接受，再扩展风光；未达到身份和控制效果目标时修改方法或缩小承诺；若核心流程比替代方案更繁琐，先简化，不增加外围功能。

## 17. 摄影技能资产与交互规则

技能是可复用的创作方法，人物保存身份，风格保存审美偏好，工作流组织技能顺序，方案保存本次输入，执行记录保存方法到结果的关系。

首版示例为原创的“机位与视觉重点规划”：输入画面目标、拍摄锚点与取景范围，并可配置观察方位、相对高度、镜头俯仰和背景存在感；输出方案字段、提示词片段和检查项。不同人物复用同一技能。

建议声明式方法，外部资料仅用于辅助提炼草稿；不自动执行外部指令、脚本、上传或生成。先人工校正、再试用与记录验证，未验证条目不得显示效果保证。

风格提供偏好、技能根据目标给建议、用户决定最终值。冲突预览，身份字段受保护；历史记录锁定版本。首版只贯通摄影槽位一个主要技能；按任务检索，查看来源与验证状态，填参数 → 预览 → 解决冲突 → 应用 → 生成 → 评价。

新增验证：至少两个人物、两种任务重复试用，记录目标是否达成；比较直接提示词与技能参数化路径的理解负担和复用时间。未执行前不报告效果通过。完整分析与原创示例见 `.wave/product/INIT-SKILL-ASSETS.md`。

## 18. Prompt 资产、预览与核心交互

新增一级“Prompt”入口，保留项目、人物、摄影技能、摄影风格、作品与常驻快捷生成。Prompt 库支持卡片 / 紧凑列表、原文关键词和题材 / 平台 / 模型 / 有无试用结果筛选；待整理、无匹配和无图各有不同提示。建议收集 / 编辑与条目详情（版本、条件、试用结果）页面，路由留给后续规划。

Prompt 保存具体表达与版本；人物保存身份；风格保存审美维度；技能保存方法 / 参数 / 检查规则；方案保存本次配置；作品与试用保存实际结果。收藏不强制转技能；Prompt 到技能为显式独立草稿，不自动训练或提炼人物身份。

预览是读取文本与已存在的本人结果。外部链接仅给出处，本人的图片给特定条件下的一次结果，均不保证重复输出。同一版本多次试用保留多组结果和满意 / 待改进评价；封面由用户选择，不自动以评分“验证”全版本。

进入快捷草稿 → 检查实际文本 / 未应用参数 → 素材传输摘要 / 输出 / 能力限制 / 费用 → 显式提交 → 原任务状态与作品规则。专业流程原有身份保护、冲突与快照规则保持。Prompt 内外部指令不触发脚本或额外网络操作。

## 19. Prompt 增量验证与交接

用 20–30 条真实收藏对照社交收藏 / 文档 + 文件夹，测量收集完成率、找回指定意图的成功率 / 耗时、找到后的实际复用率；检验新版无图与旧版封面的理解准确性。样本数为建议，无实测基线；若未改善找回和复用，先简化流程，不扩张自动化。试用成本包含失败，不能只按满意封面计算投入。
